# Herramientas financieras del asistente integrado

MCP y el transporte del asistente externo se retiraron en fase 5. La documentación
anterior del harness pertenece a ese recorrido y se conserva como
[referencia archivada](../archive/sure/llm-guides/wealth-agent-harness.md).

El asistente integrado mantiene las herramientas registradas en
`Assistant.function_classes`, incluidas las del Statement Vault y Bills con sus
gates preview, aislamiento familiar y permisos de cuentas. Los documentos y
conversaciones locales permanecen legibles y exportables; los índices remotos no
se reactivan automáticamente. Véase [fase 5](../migration/pruning-phase-5.md).

El [wealth blueprint](wealth-blueprint.md) sigue siendo arquitectura de referencia
para un sistema externo separado; no prescribe operaciones en este repositorio.
