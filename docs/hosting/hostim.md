# Relay hosting: Hostim

The inherited Sure deployment guide is retained as historical reference under
`docs/archive/sure/hosting/hostim.md`. Its upstream image, templates and setup
commands are not a Relay installation path.

Use the [Relay Docker guide](docker.md) with an explicitly built or approved Relay
image. Record the intended server, domain and storage in the
[final decision form](../migration/final-decisions.md) before adapting the
installation to this platform. There is no Relay one-click template or registry
image selected by this repository.
