# Redbark — retired account connector

This account connector was retired in phase 7. It cannot be enabled by credentials
or environment variables. Use Enable Banking, FinanceKit, manual accounts or
supported file imports. Market/FX providers are a separate capability.

Historical data and original attachments remain covered by the backup contract;
no schema or data purge is part of this phase. See the
[phase 7 record](../migration/pruning-phase-7.md). Previous setup instructions
remain available in Git history before phase 7.
